# Weekly Drafts

Store only reviewed, unpublished weekly newsletter drafts here.

Required filename:

`LOG_ON_Weekly_YYYY-MM-DD_DRAFT.md`

The date is the Sunday ending the completed Monday–Sunday reporting week in `Africa/Lagos`.

A draft may be added only after the Stage C input gate and the complete QA checklist pass. Record the input week, the seven source-log filenames, creator-profile revision/date, Composer structure version/source, QA outcome, and known caveats near the top of the draft.

**Never publish, email, forward, schedule, submit, or distribute from this workflow.** A draft in this directory is not approved for external release.
