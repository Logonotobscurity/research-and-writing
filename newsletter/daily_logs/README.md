# Daily Logs

Store one source-grounded editorial activity log per calendar day, using the exact filename:

`daily_log_YYYY-MM-DD.md`

Use the date in `Africa/Lagos`. The weekly Stage C job must locate the seven filenames for the completed Monday–Sunday week. A file with another date, a template, or a historical conversation summary does not count as a required daily log.

Each log should record:

- The date and research/editorial focus.
- Relevant findings, each with source title, URL, publisher/author where available, publication date, and access date.
- A clear distinction between verified fact, attributed report, inference, hypothesis, and unknown.
- Material caveats, disagreements, freshness limitations, and confidence limits.
- Why the finding may matter to LOG_ON's approved themes.
- Any metric with its unit, baseline, period, methodology, and direct source. Do not include an unexplained number as a performance claim.
- What should be excluded from the weekly issue and why, where relevant.

Use the blank [daily log template](daily_log_TEMPLATE.md). Replace every instruction prompt with evidence or explicitly mark it as not available. Do not backfill a date from memory.
