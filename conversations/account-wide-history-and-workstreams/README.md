## Main organising idea

A recurring pattern runs through otherwise distinct discussions:

**Investigate → understand the mechanisms → discover what is missing → define the problem → architect → build → integrate → govern and validate → measure → learn and expand.**

This connects research, product development, business systems, agent infrastructure, language intelligence, memory systems, and opportunity work without implying that all projects share the same implementation or maturity.

## Evidence conventions

- **User-stated:** directly expressed by the user.
- **Reported:** stated in prior conversation but not independently checked here.
- **Verified:** checked against an authoritative artifact during a specific task; time-bound.
- **Assistant interpretation:** analytical synthesis, not user-authored fact.
- **Joint working conclusion:** clarified or endorsed through discussion.
- **Hypothesis / proposal:** direction requiring validation.
- **Unknown:** unavailable information.

A repository name does not prove current activity or deployment. A proposed architecture is not an implementation. A historical metric is not a current metric. Notebook-generated claims require source-level checking.
