# 00 — Scope, Fidelity, and Source Hierarchy

## Scope
This archive was reconstructed from user-visible messages in the current conversation, current repository files, original files/metadata in the account Library, and retained conversation summaries where original wording was unavailable. It is not a complete account export.

## Source hierarchy
1. Exact message visible in the current conversation: verbatim transcript.
2. Original saved Library file: exact saved content or metadata reference.
3. Existing committed repository file: exact committed content linked by path/commit.
4. Persisted tool/execution report: exact result with limits.
5. Retained conversation summary: reported/reconstructed, never called transcript.
6. New archival explanation: retrospective analysis, not historical wording.

## Fidelity labels
VERBATIM-USER; VERBATIM-ASSISTANT; ORIGINAL-FILE; TOOL-RESULT; REPORTED; RECONSTRUCTED; UNKNOWN; NOT-PRODUCED; RESTRICTED.

## Library audit
The recursive Library listing returned 751 items: 742 files and 9 folders. 404 files were marked model_generated=true. The oldest/newest returned file timestamps were 15 May 2025 and 7 November 2026. These are artefact dates, not conversation boundaries.

## Public-repository privacy
Personal career/application and potentially sensitive health/medical file names are masked in the inventory. Private contents are not copied. Two source reports containing a benchmark/reference URL previously designated not for public-facing disclosure are indexed but not copied. Library file IDs are private references, not public URLs.

## Limits
This archive does not claim that every account conversation or assistant response is present; that all historic source URLs are known; that every Library asset has a public link; that a prompt summary is a full prompt; that a proposal is an executed automation; or that hidden private reasoning is part of the user-visible transcript.

## Rationale boundary
Preserve communicated explanations and concise retrospective action rationale only. Do not reproduce hidden private chain-of-thought or internal reasoning traces.


## Text-extraction normalization note

The recovered text artefacts were copied from the Library's full-text reader, which can normalize line endings. For example, the two long August pasted-text files were retrieved across all reported pages and line ranges; the difference between their Library byte size and the resulting GitHub byte size is consistent with CRLF-to-LF normalization plus the terminal newline. Their textual content and ordering are preserved, but these Markdown/text copies should not be described as byte-identical binary exports. The untouched Library item remains the canonical original file.
