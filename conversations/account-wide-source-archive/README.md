# Account-Wide Source Archive

**Record date:** 8 November 2026  
**Archive type:** Source-first chronology, recoverable verbatim exchanges, original saved outputs, prompt/version evidence, URL provenance, automation results, asset references, and gaps.  
**Coverage:** Material accessible in the current conversation, repository, and Library. This is not a complete raw export of every account conversation.

## Why this folder is separate
The existing account-wide-history-and-workstreams folder is a thematic synthesis. The research-led-systems-builder and identity-escalation-attention-hooks folders preserve focused histories. This folder adds a separate source layer: exact wording where recoverable, original saved outputs, prompt/version evidence, URLs, automation/tool results, assets, and gaps. It does not replace or rewrite those folders.

## Library audit
The recursive Library listing returned 751 items: 742 files and 9 folders. 404 files were marked model-generated. The asset index lists those 404; the full inventory lists all 742 files. The earliest/latest returned file timestamps were 15 May 2025 and 7 November 2026. These are asset dates, not account-conversation boundaries.

## Privacy and URL policy
Personal career/application and potentially sensitive health/medical file names are masked in the CSV inventory. Private document contents are not copied. Two source reports with a benchmark/reference URL previously designated not for public-facing disclosure are indexed but not copied. Library file IDs are private account references, not public URLs. Binary assets are indexed by their actual metadata; public download links are never fabricated.
